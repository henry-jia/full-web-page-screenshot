# Lessons Learned

- Visible-tab capture APIs require viewport tiling; full-page coverage is an orchestration problem, not one API call.
- Stitching must account for device-pixel scale and remainder tiles to avoid seams and silent cropping.
- Page cleanup belongs in an unconditional terminal path because capture permissions and bitmap decoding can fail mid-run.
- Modern dashboards often lock the root document to the viewport and scroll a `main` panel instead. Full-page capture must detect the actual scroll owner and offset crop/destination geometry by that panel's visible frame.
- Treat an inner scroll frame as a replaceable viewport region: expand its content, relocate trailing outer chrome, and validate the frame every segment. During cleanup, restore scrollbar geometry before coordinates, then restore smooth-scroll and snap behavior afterward.

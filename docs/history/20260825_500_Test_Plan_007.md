- Detect, scroll, and restore a dominant nested application scroller.
- Preserve the first outer viewport and stitch later segments only into the nested frame.
- Relocate trailing right/bottom chrome when a nested frame does not touch viewport edges.
- Reject partially visible or moving frames before creating a misleading bitmap.
- Prefer a large nested scroller over minor root overflow and warm both scroll axes.
- Disable and restore nested `overflow-anchor`; correct a one-shot position displacement before capture.
- Correct a one-shot window-position displacement through the same bounded retry path.
- Reject a nested target that still redirects the position after all three exact attempts.
- Reject invalid geometry while uniformly fitting oversized output to safe Canvas budgets.
- Keep source crops full resolution while independently scaling destination placement.
- Sanitize filenames and map internal errors to user-facing copy.

# Roadmap

## MVP

- Capture complete horizontal and vertical page bounds.
- Stitch captured viewport segments into one local PNG.
- Restore page state and explain unsupported-page failures.
- Provide automated planning tests and a manual Firefox smoke test.
- Validate a real long-page capture in Firefox.
- Publish a deterministic GitHub release package and submit version 0.1.0 to AMO.

## Later

- Optional JPEG/WebP output and quality controls.
- Region selection and copy-to-clipboard.
- Automated Firefox integration tests.

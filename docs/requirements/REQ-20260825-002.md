## 1. 原始輸入

在功能實頁驗收成功後，建立本地 Git 並排除機密資訊，公開發布到 `henry-jia/full-web-page-screenshot`，建立可供 Mozilla 審核的 GitHub Release 套件，提供英中日三語 README 與安裝說明，並以 `full-web-page-screenshot@henry-jia.github.io` 和 MPL-2.0 授權提交 Firefox AMO。若 AMO ID 衝突，或必須由擁有者完成登入、MFA、法律確認，立即停止並提供精確交接。

## 2. 用户故事

- US-1: As the extension owner, I want a reviewed public GitHub repository and versioned release, so that source and release artifacts are traceable.
- US-2: As a Firefox user, I want clear English, Chinese, and Japanese installation instructions, so that I can install the extension through the supported channel.
- US-3: As the extension owner, I want an AMO submission with a stable ID, explicit privacy declaration, and MPL-2.0 license, so that Firefox users can receive a Mozilla-signed extension.

## 3. 验收标准

- [ ] AC-1: 本地 repository 使用 `main`，首次 commit 只包含已審查檔案，不包含 `dist/`、憑證、本機設定或私密截圖。
- [ ] AC-2: 公開 GitHub repository 為 `henry-jia/full-web-page-screenshot`，其 `main` 指向本地已驗證 commit。
- [ ] AC-3: `v0.1.0` GitHub Release 附加 deterministic AMO submission ZIP 與匹配的 SHA-256 檔案，並清楚說明未簽署 ZIP 不能當作一般 Firefox XPI 安裝。
- [ ] AC-4: 根目錄提供 English、繁體中文及日本語 README，包含隱私、建置、驗證、臨時安裝、AMO 安裝與已知限制。
- [ ] AC-5: source repository 明確採用 Mozilla Public License 2.0，LICENSE 正文與官方 MPL-2.0 一致。
- [ ] AC-6: 發布前 `npm test`、`npm run check` 及 Mozilla `web-ext lint` 全部通過，extension package 沒有機密或資料傳輸程式碼。
- [ ] AC-7: AMO submission 使用 add-on ID `full-web-page-screenshot@henry-jia.github.io`、Firefox Desktop、無資料收集聲明及 MPL-2.0；若 ID 已存在，不使用其他 ID 繼續提交。
- [ ] AC-8: 若 AMO 要求 owner-only 登入、MFA 或法律確認，agent 停在該頁並告知擁有者需要完成的單一互動，不索取或處理密碼、MFA code 或 token。

## 3.5 深度合约（Depth Contract）— 反浅薄
> verified-build skill 的 Step 1 消费这一节。
- **深模块期望**: Release pipeline 吸收 deterministic packaging、checksum、秘密排除、AMO manifest lint、版本與 ID 一致性；擁有者只需做一次公開發布決策及無法代辦的帳號或法律互動。
- **预登记浅薄失败模式**: 直接上傳來源資料夾；把未簽署 ZIP 改名成 XPI；commit `dist/`、token 或私密截圖；README 只有單一語言；未驗證 ID 就改用其他 ID；跳過 AMO lint 或將警告當成功。
- **不变量**: 不提交或輸出憑證；GitHub tag 必須指向已驗證 source commit；Release artifact 必須由同一 source state 建置；AMO ID 衝突時 fail closed；頁面資料仍不得離開本機。

## 4. 范围边界

### In Scope
- 本地 Git 初始化、首次 commit、公開 GitHub repository、`v0.1.0` tag 與 Release。
- deterministic ZIP／SHA-256、三語 README、MPL-2.0、隱私及 AMO listing 文件。
- Firefox Desktop AMO 公開提交與 owner-only 互動的精確交接。

### Out of Scope
- Firefox for Android 上架、Chrome／Edge 商店、付費功能、雲端服務或遙測。
- 自動處理密碼、MFA、API token、法律聲明或 AMO reviewer 的後續人工決定。
- AMO ID 衝突時自行改名或使用替代 ID。

## 5. 关键约束

- **技术**: Firefox Manifest V2、Firefox 142+、Node.js 20+、PowerShell 7、GitHub CLI、Mozilla web-ext validator。
- **业务**: GitHub repository 公開；GitHub owner 為 `henry-jia`；版本 `0.1.0`；授權 MPL-2.0；AMO ID 必須保持指定值。
- **非功能性**: deterministic artifact、最小權限、零資料傳輸、可稽核 commit/tag/checksum、英中日文件同步。

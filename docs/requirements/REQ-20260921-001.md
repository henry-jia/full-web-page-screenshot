## 1. 原始输入

使用者（繁體中文，附兩張截圖）：希望增加一個高級功能——對頁面中某個自帶捲動條的子區域進行完整捲動截圖。範例是 Voice2Text 頁面（`http://192.168.1.16:8443`）的「逐字時間軸」面板：頁面本身可捲動，該面板又是獨立的可捲動子區域，整頁截圖只能拍到面板目前可見的部分。使用者同時問：區域截圖是否可以跟完整頁面截圖結合（整頁 + 子區域展開內嵌），還是只能單獨截取子區域——要求先分析再決定。

截图描述（kimi-code session 媒體原件）：第一張為 Voice2Text 結果頁頂部視角，右側「TIMELINE / 逐字時間軸」面板顯示片段 265 段、3 位說話人，面板自身有捲動條；第二張為視窗向下捲動後的視角，時間軸面板仍在頁面中段，顯示其內容遠超一屏。

## 2. 用户故事

- US-1: As a Firefox user, I want to point at a scrollable sub-region of the page and capture its entire scroll content as one PNG, so that content scrolled out of view inside that region (e.g. a long transcript timeline) is preserved instead of truncated.
- US-2: As a Firefox user, I want the picker to clearly highlight which scrollable element will be captured before I confirm, so that I never capture the wrong region.
- US-3: As the extension owner, I want region capture to reuse the verified element-mode pipeline (warmup, scroll verification, stitching, downscale budget), so that the new feature does not introduce a second capture engine to audit.

## 3. 验收标准

- [ ] AC-1: popup 提供「擷取捲動區域」入口；點擊後目前分頁進入選取模式，滑鼠懸停時以高亮框標出命中的可捲動元素（overflow 為 auto/scroll/overlay 且捲動範圍 > 1 CSS px），游標移入不可捲動元素時高亮其最近的可捲動祖先；無任何可捲動祖先時不給高亮。
- [ ] AC-2: 在選取模式點擊確認後，擴充功能捲動該元素的全部垂直與水平捲動範圍，拼接並下載一張只包含該元素可見框（client 區域）內容的 PNG；輸出不含框外頁面像素。
- [ ] AC-3: 擷取結束後（成功、失敗或取消）該元素的 scrollTop/scrollLeft、被暫改的 inline style、以及整頁捲動位置都完整還原，頁面無殘留 DOM 變更。
- [ ] AC-4: 選取模式可用 Escape 鍵取消；取消後 popup 回到待命狀態，頁面無任何變更殘留。
- [ ] AC-5: 擷取期間選定元素的尺寸、位置或捲動上限改變時，擷取 fail closed，popup 顯示繁體中文錯誤訊息，不輸出錯位或裁切的圖片。
- [ ] AC-6: 區域輸出遵守既有 canvas 安全預算（32767 px 邊長、6400 萬像素、500 段上限）；超限時沿用既有等比例縮小邏輯並在完成訊息中顯示最終尺寸。
- [ ] AC-7: 既有「擷取完整頁面」路徑行為不變：`npm test` 與 `npm run check` 全部通過，新增 picker 與區域裁切邏輯有對應 Node 測試。

## 3.5 深度合约（Depth Contract）— 反浅薄
> verified-build skill 的 Step 1 消费这一节。
- **深模块期望**: picker 模組吸收 hover 命中、可捲動祖先解析、高亮覆層生命週期與取消清理；capture 側把「使用者選定元素」正規化為既有 `scrollTarget` + frame 描述符，讓 background 的拼接、邊緣容差、調整與縮放管線無需分叉；呼叫方（popup）只發起一次意圖，不處理捲動細節。
- **预登记浅薄失败模式**: 只對元素目前可見範圍截一張圖就當完成；用 `getBoundingClientRect` 一次擷取而不捲動；把自動 dominant-scroller 偵測結果直接當使用者選擇、不給確認；選取時寫入元素 style 卻不還原；輸出混入框外頁面像素；忽略水平捲動範圍；取消選取後殘留高亮覆層或事件監聽。
- **不变量**: 頁面資料不出本機、無網路呼叫；擷取前後頁面狀態完全一致（捲動位置、inline style、DOM）；捲動落點不一致或幾何改變時 fail closed，不輸出已知錯位的圖片；既有 full-page 路徑行為與測試不退化。

## 4. 范围边界

### In Scope
- popup 第二入口與頁面內 picker（hover 高亮、點擊確認、Escape 取消）。
- 對選定可捲動元素的完整垂直＋水平捲動截圖，輸出裁切到該元素 client 框的單張 PNG。
- 複用既有 element-mode 管線：預熱、捲動驗證（含捲動邊緣 1 px 容差）、fixed/sticky 處理、拼接、安全縮放、還原。
- picker 與區域裁切的 Node 測試；繁體中文介面文案與錯誤訊息。

### Out of Scope
- 整頁與子區域的合併輸出（window 與 element 雙捲動座標拼接）——2026-09-21 使用者決定本需求只做區域-only（方案一），合併輸出若需要另立需求。
- 一次擷取多個區域；對不可捲動內容的自由矩形框選截圖。
- 截圖後的標註、編輯、OCR 或上傳功能。
- Chrome／Edge 相容與 Firefox for Android。

## 5. 关键约束

- **技术**: Firefox Manifest V2、Firefox 142+、plain JavaScript（無新依賴）、Node.js 20+ 測試；瀏覽器無關的幾何計算放 `extension/capture-plan.js` 並以 Node 測試覆蓋。
- **业务**: 介面與錯誤訊息一律繁體中文；程式碼與識別字用英文；送審 AMO 前維持無資料收集聲明成立。
- **非功能性**: 零資料傳輸、零遙測；所有暫改的頁面狀態必須可完整還原；fail closed 哲學（寧可中止不可錯位）；`npm test`、`npm run check` 全綠才算完成。

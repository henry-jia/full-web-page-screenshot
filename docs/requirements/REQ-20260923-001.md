## 1. 原始输入

使用者（繁體中文，2026-09-23）：目前截圖後插件只顯示截圖完成，使用者要到 download 目錄自己找圖片。希望新版本截圖完成後，插件 UI 上顯示一個不大的縮圖；點擊縮圖後彈出新視窗，允許使用者編輯圖片，提供常用工具：輸入文字、畫矩形、圓形（橢圓）、拉線段、箭頭線段、指定區域的馬賽克等。編輯完成後再儲存為圖片檔案，並告知使用者儲存的路徑和檔名。

## 2. 用户故事

- US-1: As a Firefox user, I want to see a small thumbnail in the popup after a capture completes, so that I can confirm the result without opening the download folder.
- US-2: As a Firefox user, I want to click the thumbnail to open an editor window with annotation tools (text, rectangle, ellipse, line, arrow, mosaic), so that I can mark up the screenshot before saving it.
- US-3: As a Firefox user, I want the editor to tell me the saved file's path and name after I save, so that I can find the file immediately.

## 3. 验收标准

- [x] AC-1: 截取成功（整頁或區域）後 popup 顯示等比縮圖（最長邊 ≤ 240 CSS px）；無成功截取結果時不顯示縮圖。（Node 測試斷言成功態攜帶縮圖與 imageUrl）
- [ ] AC-2: 點擊縮圖時，擴充功能開啟新視窗載入編輯器，編輯器載入最近一次成功截取的**完整解析度**圖片；無可用圖片時不開窗並在 popup 顯示提示。（OPEN_EDITOR 訊息流有 Node 測試；視窗載入需實機驗證）
- [ ] AC-3: 編輯器提供六種工具——文字、矩形、橢圓、直線、箭頭線段、區域馬賽克；可選顏色（至少紅/黃/藍/綠/白/黑）與筆畫粗細（至少 3 檔）；所有繪製作用於原始解析度畫布，輸出無縮放損失。（指令繪製有 Node 測試；實機操作需手動驗證）
- [x] AC-4: 編輯器支援復原（undo 按鈕與 Ctrl+Z），至少 10 步；復原後畫布與操作歷史一致。（指令重放，無步數上限）
- [ ] AC-5: 編輯器「儲存」將目前畫布輸出為 PNG 下載（檔名為原截取檔名去副檔名加 `-edited.png`），完成後在編輯器內顯示實際儲存路徑與檔名；下載失敗時顯示錯誤訊息且不誤報成功。（需實機驗證路徑顯示）
- [x] AC-6: 既有行為不變：截取完成仍自動下載原始 PNG；`npm test` 與 `npm run check` 全綠；註解幾何、指令重放、undo、馬賽克分塊與 background 影像生命週期有對應 Node 測試。

## 3.5 深度合约（Depth Contract）— 反浅薄
> verified-build skill 的 Step 1 消费这一节。
- **深模块期望**: 註解引擎（`extension/annotate.js`，比照 capture-plan.js 的瀏覽器無關 UMD 模式）把工具操作正規化為可序列化指令並負責確定性重放——undo 是「移除指令後重放」，不存整張影像快照；箭頭幾何、矩形正規化、馬賽克分塊皆為純函數。編輯器 UI 只把滑鼠/鍵盤手勢翻譯成指令；background 只管影像物件 URL 與縮圖的生命週期及下載，不感知編輯語義。
- **预登记浅薄失败模式**: 在 CSS 縮放後的顯示畫布上直接繪製導致輸出被縮小或座標偏移；undo 用整張 ImageData 快照導致 6400 萬像素大圖記憶體爆量；文字工具用 `prompt()`；馬賽克用半透明色塊遮罩（可被移除還原原圖）而非真像素化；編輯儲存覆蓋原始檔案；popup 直接載入原圖當縮圖造成大卡頓；blob/object URL 永不釋放造成記憶體洩漏。
- **不变量**: 影像資料不出本機、零網路呼叫、零遙測、無新權限、無新依賴；截取完成仍自動下載原始 PNG（既有行為不破壞）；編輯輸出另存新檔不覆蓋原檔；指令重放結果與操作順序嚴格一致；`default_locale` 恆為 `zh_TW`。

## 4. 范围边界

### In Scope
- popup 成功態縮圖與點擊開啟編輯器。
- 編輯器新視窗：六種工具、顏色與筆畫粗細選擇、undo（按鈕 + Ctrl+Z）、儲存並顯示實際路徑與檔名。
- background 的影像/縮圖/object URL 生命週期管理（新截取或分頁關閉時釋放）。
- 編輯器與 popup 新文案的 zh_TW/en i18n；註解引擎與 background 生命週期的 Node 測試。

### Out of Scope
- 裁切、旋轉、濾鏡、模糊（馬賽克以外的局部濾鏡）、貼圖、手寫自由筆。
- 多張歷史截圖管理、圖片庫、雲端分享或上傳。
- 編輯器的 redo、拖移已提交圖形、快捷鍵全家桶。
- Chrome/Edge 相容與 Firefox for Android。

## 5. 关键约束

- **技术**: Firefox Manifest V2、plain JavaScript（無新依賴）、Node.js 20+ 測試；瀏覽器無關邏輯放 `extension/annotate.js` 並以 Node 測試覆蓋；編輯器視窗以 `browser.windows.create` 開啟擴充功能內頁；影像以同源 object URL 傳遞。
- **业务**: 介面文案走既有 i18n 架構（zh_TW 預設 + en）；AMO 無資料收集聲明維持成立。
- **非功能性**: 大圖（安全預算上限 6400 萬像素）下 undo 不得持有整張快照；object URL 必須可釋放；`npm test` 與 `npm run check` 全綠才算完成。
